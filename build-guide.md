
# 🧩 Общая архитектура проекта (по состоянию на данный коммит)

## 1. Подключение автозагрузки и структура запуска

**Файл:** `public/index.php`

Главная точка входа в приложение.

### Что делает:
- Устанавливает точку отсчета времени для измерения производительности.
- Проверяет версию PHP.
- Подключает 3 важных файла:
    1. `config/config.php` — файл с глобальными константами и настройками.
    2. `vendor/autoload.php` — Composer-автозагрузка.
    3. `helpers.php` — файл с глобальными вспомогательными функциями.
- Запускает основное приложение через `new Application();`.
- Отображает, сколько времени занял запуск через функцию `dump()` (а не `print_r`).

### Использование автозагрузки:
Подключение `vendor/autoload.php` говорит о том, что в проекте настроен Composer. Классы загружаются автоматически на основе пространства имён.

### Отладка:
Происходит переход от `print_r` к `dump()`, что указывает на установку **VarDumper от Symfony** — более удобный способ для вывода переменных при разработке.

## 2. Глобальные вспомогательные функции

**Файл:** `helpers.php`

Содержит 2 глобальные функции:

### `app(): \Core\Application`
Возвращает текущий экземпляр главного класса приложения. Использует статическое свойство `Application::$app`.

### `request(): \Core\Request`
Возвращает объект текущего HTTP-запроса — `Request`, который создаётся внутри `Application`.

### Зачем нужно:
Позволяет обращаться к ключевым объектам без необходимости передавать их явно в каждую функцию или класс.

## 3. Класс Request

**Файл:** `core/Request.php`  
**Пространство имён:** `Core`

Класс, инкапсулирующий всю работу с HTTP-запросами.

### 📦 Свойства:

- `public string $uri`  
  Содержит очищенный URI (обрезанные слэши, декодированный). Открытое свойство, т.к. может использоваться напрямую в представлении или роутере. Возможно, позже будет инкапсулироваться через геттер.

### 🧠 Методы:

- `__construct($uri)` — очищает и сохраняет URI, отлаживает через `dump()`.
- `getMethod(): string` — возвращает HTTP-метод.
- `isGet(): bool`, `isPost(): bool`, `isAjax(): bool` — булевы методы для проверки типа запроса.
- `get($name, $default = null): ?string` — безопасно извлекает `$_GET`.
- `post($name, $default = null): ?string` — безопасно извлекает `$_POST`.

### 💬 Инкапсуляция:
Прямой доступ к суперглобальным массивам закрыт — используются методы. Это упрощает тестирование, делает код контролируемым и безопасным.

## 4. Класс Application

**Файл:** `core/Application.php`  
**Пространство имён:** `Core`

Главный объект всего приложения.

### 📦 Свойства:

- `protected string $uri`  
  Хранит URI запроса. Инкапсулированное свойство — доступно только внутри класса и дочерних.

- `public Request $request`  
  Экземпляр класса `Request`. Открытое — используется из других компонентов.

- `public static Application $app`  
  Статическое свойство для глобального доступа к текущему экземпляру.

### 🧠 Метод `__construct()`

- Сохраняет текущий объект в `Application::$app`.
- Извлекает `$_SERVER['REQUEST_URI']`.
- Создаёт `Request` и передаёт URI.

### 💬 Инкапсуляция:
- `$uri` — `protected`, чтобы его нельзя было случайно изменить извне.
- Глобальный доступ к приложению возможен, но с контролем.

---

## 📌 Как всё вместе работает

1. `index.php` запускает приложение через `new Application()`.
2. Создаётся объект `Request`.
3. Через `app()` и `request()` можно получить доступ к ключевым объектам.

Пример:

```php
if (request()->isPost()) {
    $id = request()->post('id');
}
```
